Read before testing

• Both phones need internet for this version. Calls may use mobile data.
• Allow camera and microphone access when asked.
• Open this page over HTTPS (for example, through GitHub Pages). Browser camera/microphone access requires a secure context.
• This prototype uses a public signalling service and has no account system, call notifications, or production-grade TURN relay. It is for testing, not private or dependable everyday calls.
• Don't share call IDs publicly. Close the page when finished.
